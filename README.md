# 2026 数学建模项目：Q1/Q2

本仓库按项目范围整理了问题1、问题2的计算源码、结果数据、现有图表与论文分章稿。

## 内容

- `src/`：Q1/Q2 数值模型、结果导出与章节资产代码。
- `tools/`：项目输入、结果和论文构建相关工具源码。
- `config/`：Q1/Q2 模型及已完成计算的运行/输出配置。
- `results/q1/`、`results/q2/`：关键结果表与全精度数据文件。
- `figures/`：Q1/Q2 现有图表（独立图件，尚未并入章节正文）。
- `paper/`：Q1/Q2 LaTeX 章节、生成表格/数值宏、参考文献与独立预览 PDF。
- `requirements-lock.txt`：计算依赖版本记录。

## 当前状态与范围

Q1、Q2 的计算结果已完成技术验收；论文目录提供的是 Q1/Q2 独立章节草稿和预览，不是完整参赛论文。Q3 的生产方案尚未确认，Q4 结果也不在本次导出范围，因此未包含相关候选代码、图表或演示材料。

为遵守“仅上传源码、图表、关键数据和论文”的要求，仓库不包含原始题目/附件、身份或报名资料、内部复核记录、临时文件和历史演练材料。缺少原始附件时，克隆仓库不能单独重现全部计算；配置和结果文件保留必要的模型参数、关键输出及追溯信息。

数值验收表示对已选方程和计算设置的数值证据，不等于材料物理真实性验证或队员人工审稿。独立章节的图表整合、整篇论文复核和最终提交门控仍需另行完成。
